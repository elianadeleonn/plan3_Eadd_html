Diseño web

Diseño Visual: El diseño web busca que una página sea atractiva, ordenada y fácil de entender. Para lograrlo se utilizan colores, tipografías, imágenes y espacios de forma equilibrada.


Diseño responsivo: El diseño web busca que una página sea atractiva, ordenada y fácil de entender. Para lograrlo se utilizan colores, tipografías, imágenes y espacios de forma equilibrada.

Experiencia de Usuario: La experiencia de usuario consiste en facilitar la navegación dentro de una página web. Los botones, menús y enlaces deben ser claros y fáciles de encontra

Accesibilidad web: La accesibilidad permite que más personas puedan utilizar un sitio web sin dificultades. Para ello se recomienda usar textos legibles, buen contraste y una estructura organizada.
