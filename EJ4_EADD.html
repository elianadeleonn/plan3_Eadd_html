Java

Java es un lenguaje de programación orientado a objetos, utilizado para crear aplicaciones de escritorio, sistemas empresariales y aplicaciones Android.

Python

Python es un lenguaje sencillo y fácil de aprender. Se utiliza en desarrollo web, inteligencia artificial, automatización y análisis de datos.

Kotlin

Kotlin es un lenguaje moderno desarrollado por JetBrains. Se usa principalmente para crear aplicaciones Android y es compatible con Java.
